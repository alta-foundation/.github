# Code of Conduct

We want ALTA's repositories to be welcoming places for practical, respectful collaboration.

## Expected behavior

- Discuss ideas and code on their merits; explain disagreements with evidence.
- Be considerate of different backgrounds, experience levels, and communication styles.
- Respect privacy. Do not post personal data, private conversations, or credentials.
- Assume good intent where reasonable, and accept constructive feedback.

Harassment, threats, discrimination, sexualized attention, personal attacks, and persistent disruption are not acceptable. These rules apply to repository discussions, issues, pull requests, and related community spaces.

Maintainers may edit or remove content, close discussions, or restrict participation when needed. Decisions are made case by case; this document does not promise a particular outcome or response time.

To flag abusive content, use GitHub's **Report content** option. If you need to raise a conduct concern without posting details publicly, open a minimal issue asking maintainers for a private contact route, with no identifying or sensitive details. For security vulnerabilities, use [SECURITY.md](SECURITY.md).
