# ALTA Foundation

ALTA develops modular, user-controlled AI infrastructure. Our current work includes a personal second brain: tools to import information, preserve its provenance, build a useful memory, and make it available to local agents.

This organization also hosts other ALTA projects. Each repository's README describes its own purpose, maturity, setup, and license. Some components are still being prepared for public contribution.

We aim to make the reusable software open source and keep personal data and customer configurations outside public repositories. See [contribution guidelines](https://github.com/alta-foundation/.github/blob/main/CONTRIBUTING.md) and the [security policy](https://github.com/alta-foundation/.github/blob/main/SECURITY.md) before participating.
